# 🔐 Muhasebe CRM - Güvenli İş Yönetim Sistemi

Muhasebe ofisleri için tam entegreli CRM sistemi

## 📦 Özellikler

✅ Müşteri yönetimi
✅ İş takibi ve havale
✅ Gmail/Drive/WhatsApp/Grandstream entegrasyonu
✅ Denetim kayıtları
✅ Rol tabanlı erişim kontrolü

## 🚀 Başlangıç

### Backend

```bash
cd crm-backend
npm install
docker-compose up -d
npm run dev
```

### Frontend

```bash
cd crm-frontend
npm install
npm start
```

## 🔐 Güvenlik

- JWT token-based authentication
- Encrypted credentials storage
- RBAC (Role-Based Access Control)
- Comprehensive audit logging
